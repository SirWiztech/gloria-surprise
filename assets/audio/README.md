# Music

`music.wav` is an original, gentle 48-second ambient loop written for this
project. It is off by default and only starts when Gloria taps the music
button on the final screen.

To use your own song, replace `music.wav` with another WAV file (keeping the
filename), or point the `<source>` tag in `index.php` at an MP3 you add here.

If the file cannot be played, the music button hides itself instead of showing
a broken control.
